Agent Dashboard

A local browser dashboard for managing Codex and Devin sessions with a hard provider switch, embedded terminals, live status, search, archive/restore, previews, and provider-scoped analytics. The Avalonia native desktop app shares the same provider catalog and scopes its sessions, terminals, and analytics to the selected Agent.

Prerequisites

  • Node.js 18 or newer.
  • Codex CLI installed and run at least once for the Codex dashboard.
  • Devin CLI installed and run at least once for the Devin dashboard.
  • Local Codex state under ~/.codex, including state_*.sqlite and rollout JSONL files.
  • Local Devin state under ~/.local/share/devin/cli/sessions.db or $XDG_DATA_HOME/devin/cli/sessions.db.
  • For tests: Playwright Chromium installed with npx playwright install chromium.

Run

npm install
npm run build
npm start

Open http://localhost:7575.

PM2

npm run pm2:start
npm run pm2:restart
npm run pm2:logs
npm run pm2:stop
After server-side changes, use npm run pm2:restart. A build alone does not replace the Node process already running under PM2.

What It Reads

  • Codex thread metadata from ~/.codex/state_*.sqlite.
  • Codex conversation and tool history from ~/.codex/sessions/**/*.jsonl.
  • Codex CLI and VS Code extension sessions from the same local Codex thread store.
  • Devin session metadata and message history from Devin sessions.db.
  • Provider-scoped dashboard metadata for title overrides and archive state.

What It Changes

  • New sessions launch the selected local provider CLI in the selected working directory.
  • Existing Codex sessions resume with codex resume <session-id>.
  • Existing Devin sessions resume with devin --resume <session-id> --respect-workspace-trust false.
  • Codex archive and restore call codex archive and codex unarchive.
  • Devin archive and restore use dashboard-local archive metadata.
  • Codex session renames are dashboard-local; Devin renames update Devin's session title field.

Configuration

  • PORT: HTTP server port, default 7575.
  • CODEX_HOME: Codex home directory, default ~/.codex.
  • CODEX_STATE_DB_PATH: explicit Codex state SQLite path.
  • UI_MY_CLI_DB_PATH: explicit dashboard metadata SQLite path.
  • DEVIN_DB_PATH: explicit Devin sessions.db path.
  • DEVIN_DASHBOARD_DB_PATH: explicit Devin dashboard metadata SQLite path.
  • UI_MY_CLI_DEFAULT_PROVIDER: default provider for compatibility routes, default codex.

Testing

npm run build
npm run docs:check
npm run test:smoke

Playwright tests expect the PM2-managed server to already be running on the configured port.
